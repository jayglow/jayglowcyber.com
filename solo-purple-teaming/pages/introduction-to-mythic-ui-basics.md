<h2 id="introduction"><strong>Introduction</strong></h2>
<p>In this lecture, we will walk through some key features of the
<strong>Mythic C2 framework UI</strong>. While this is
<strong>not</strong> a complete course on Mythic or the UI, you need a
basic understanding of how to navigate it so you can effectively solo
purple team using the framework.</p>
<p>We’ll explore the <strong>main dashboard</strong> and essential
icons, giving you the foundation to interact with agents, manage
callbacks, and prepare for future operations.</p>
<hr />
<h3 id="1-accessing-the-mythic-dashboard"><strong>1. Accessing the
Mythic Dashboard</strong></h3>
<ul>
<li>The <strong>Mythic Dashboard</strong> is your <strong>command
center</strong>.</li>
</ul>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image.png"
alt="image.png" /></p>
<ul>
<li>From here, you can:
<ul>
<li>Monitor <strong>callbacks</strong> (active agent connections)</li>
<li>Manage <strong>implants</strong></li>
<li>Interact with <strong>target systems</strong></li>
</ul></li>
<li>The interface is <strong>clean</strong>, <strong>modular</strong>,
and <strong>scales well</strong> for larger red team operations.</li>
<li><strong>Dashboard Elements</strong> include:
<ul>
<li><strong>Task Status</strong> – tracks running and completed
tasks.</li>
<li><strong>Number of Callbacks</strong> – shows active sessions with
compromised hosts.</li>
<li><strong>Top Command Stats</strong> – displays the most frequently
executed commands.</li>
</ul></li>
</ul>
<hr />
<h3 id="2-profiles-and-payload-types"><strong>2. Profiles and Payload
Types</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%201.png"
alt="image.png" /></p>
<ul>
<li>Click the <strong>Profiles &amp; Payload Types</strong> icon to
view:
<ul>
<li><strong>Agents Installed</strong> – e.g., <em>Apollo Agent</em></li>
<li><strong>C2 Profiles</strong> – such as HTTP and SMB</li>
<li><strong>Service Wrappers</strong> – additional operational
components.</li>
</ul></li>
</ul>
<hr />
<h3 id="3-search-function"><strong>3. Search Function</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%202.png"
alt="image.png" /></p>
<ul>
<li>The <strong>Search</strong> icon allows you to:
<ul>
<li>Look up specific information within your operation</li>
<li>Search by agent, callback, or collected indicators.</li>
</ul></li>
</ul>
<hr />
<h3 id="4-files-section"><strong>4. Files Section</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%203.png"
alt="image.png" /></p>
<ul>
<li>Contains <strong>all transferred files</strong> in the operation:
<ul>
<li><strong>Downloads</strong> – view files pulled from targets.</li>
<li><strong>Uploads</strong> – review files sent to targets.</li>
<li><strong>File Browser</strong> – navigate retrieved directories.</li>
<li><strong>Screenshots</strong> – view images captured from the target
system.</li>
</ul></li>
<li>Some <strong>event workflow tools</strong> are also accessible here
(covered in later lectures).</li>
</ul>
<hr />
<h3 id="5-artifacts"><strong>5. Artifacts</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%204.png"
alt="image.png" /></p>
<ul>
<li>Any artifact generated by a task (e.g., file creation, process
execution) is stored here.</li>
<li>Useful for <strong>post-operation review</strong> and
<strong>forensics</strong>.</li>
</ul>
<hr />
<h3 id="6-proxies"><strong>6. Proxies</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%205.png"
alt="image.png" /></p>
<ul>
<li>Displays <strong>SOCKS proxies</strong> or tunneling configurations
in use.</li>
<li>Essential for pivoting into other network segments.</li>
</ul>
<hr />
<h3 id="7-screenshots"><strong>7. Screenshots</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%206.png"
alt="image.png" /></p>
<ul>
<li>Stores all <strong>captured screenshots</strong> from compromised
hosts.</li>
</ul>
<hr />
<h3 id="8-credentials"><strong>8. Credentials</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%207.png"
alt="image.png" /></p>
<ul>
<li>Central location for all <strong>collected
credentials</strong>.</li>
<li>Supports sorting and filtering for quick access.</li>
</ul>
<hr />
<h3 id="9-active-callbacks"><strong>9. Active Callbacks</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%208.png"
alt="image.png" /></p>
<ul>
<li><strong>One of the most important icons.</strong></li>
<li>Shows <strong>live agent connections</strong>.</li>
<li>When an <strong>assumed breach host</strong> (e.g., in the <em>ecoin
domain</em>) calls back, you’ll see it here.</li>
<li>Clicking a callback lets you:
<ul>
<li><strong>Interact</strong> with the compromised host.</li>
<li><strong>Issue tasks</strong> directly to the agent.</li>
</ul></li>
</ul>
<hr />
<h3 id="10-operations"><strong>10. Operations</strong></h3>
<p><img src="/assets/images/solo-purple-teaming/introduction-to-mythic-ui-basics/image%209.png"
alt="image.png" /></p>
<ul>
<li>Displays the current <strong>operation name</strong> (e.g., <em>Test
Apollo Reflection</em>).</li>
<li>Clicking it shows:
<ul>
<li><strong>Command lists</strong> for the operation.</li>
<li>Options to <strong>create new operations</strong> (used in future
lectures for <em>Level Zero Attack Path</em>).</li>
</ul></li>
</ul>
<hr />
<h3 id="action-before-moving-on"><strong>Action Before Moving
On</strong></h3>
<ul>
<li>Spend a few minutes exploring the Mythic UI.</li>
<li>Check:
<ul>
<li>Which <strong>listeners</strong> are installed.</li>
<li>Which <strong>payload types</strong> are available.</li>
</ul></li>
<li>Familiarize yourself with each main icon so you can quickly navigate
during live operations.</li>
</ul>

Settings</strong> and how to tailor the environment to your
